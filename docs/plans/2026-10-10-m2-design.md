# M2 — Organize and pack

The owner authorized continuing while away, including the next phase. Implement M2 on top of the
optional-photo branch. Actual phone capture acceptance remains pending; this does not waive that gate.

Keep schema 1. Domain commands express explicit metadata patches, moves, original-room correction,
decision/progress transitions, trash, and restore. Transactions compare the displayed revision, validate
the current document, and apply only command fields. Bulk work runs with bounded concurrency and reports
each item independently. Editing never changes review status implicitly. Values use integer minor units
with currency-specific precision; defaults do not rewrite existing values.

Load all metadata in 250-document server pages before enabling whole-inventory search. Grid and table
share filters and selection. Owned, review inbox, completed archive, and trash use derived predicates.
Details retain filters on return and offer explicit review-next navigation. Photos continue using the
existing authenticated, bounded session; no photo replacement or permanent deletion belongs here.

Rooms and boxes have stable IDs, revision checks, rename/sort/archive controls, and duplicate warnings.
Before archiving, read a location revision, inspect current owned contents, then transact against that
same revision. Capture and new location assignments increment the destination's existing revision in
their transaction, so an assignment racing that inspection causes a conflict. Rules verify active
destinations and valid fields; collection-wide emptiness is an application invariant because rules cannot
query arbitrary contents. Archived historical labels remain available. No schema counter is introduced.

Test domain transitions, money precision, complete search, partial bulk outcomes, contested edits,
location occupancy, and positive/negative authorization. Add browser coverage for desktop organization
and a synthetic twenty-item/two-room SDK workflow. Run the full command contract. Update evidence and
create a stacked PR while the optional-photo PR is open. Deployment uses the standing explicit release
authorization only after checks pass. Export/import, permanent deletion, and orphan maintenance remain M3.
